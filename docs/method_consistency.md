# 论文与框架的方法逻辑核对

核对日期：2026-11-08。依据最新版《Manuscript.docx》的方法、第4.1–4.3节及原始RF研究脚本，并参考XGBoost原脚本确认方法含义。结论：框架的核心PU Bagging逻辑与论文一致。模型和优化器可替换是作者要求的通用化设计。

| 论文方法 | 框架实现与核对结果 |
|---|---|
| 已知正样本固定，背景真实类别未知 | 每轮使用全部正样本和抽中的未标记背景，背景临时标记为0 |
| 每轮均匀不放回，跨轮可以重复 | `training_draw`与`draw_indices`实现同样的抽样逻辑 |
| 联合搜索模型参数、正类权重和抽样比例 | 优化接口支持模型参数、正类权重及背景/正样本数量比 |
| 每组候选参数20次初筛、五折空间验证 | 研究模板设置20次和五折；每轮取折AUC均值，再取跨轮均值评分 |
| 30 km × 30 km区块避免同块样本跨训练/验证集 | 研究模板使用投影坐标下30000单位区块和GroupKFold；坐标单位须为米 |
| 先选最优比例，再据覆盖率确定最终次数 | `pipeline.run`在参数选择后调用`planned_rounds`；预检查仅报告比例不变时的预计次数 |
| 固定参数后重复抽样评估AUC | 保存每轮及每折AUC，跨轮标准差采用总体标准差 |
| 每轮用全部正样本与本轮背景拟合、预测区域 | 最终集成训练与交叉验证分开进行，与原脚本一致 |
| 平均各轮地热概率场 | 逐位置计算所有成员预测均值；额外导出成员标准差 |
| SHAP重要性来自所有子模型 | 每轮计算平均绝对SHAP，再汇总跨轮均值和标准差；全部训练行需设置`max_samples: null` |
| SHAP依赖关系汇总所有轮次，约5%等频分箱 | 合并原始特征值与SHAP值，20分位箱；保留原脚本两端各1%的默认截尾设置 |

## 范围与复现

按作者要求，本框架包含单模型的完整PU Bagging、评估、SHAP、绘图及结果输出，不纳入两模型共识分区。正样本整理、缓冲区排除和特征栅格制作属于输入数据准备，应在运行前完成。

通用代码不固定103个正样本、86473个背景或论文的213/191次运行结果。最终次数根据实际有效样本量与选定比例计算；如需采用论文已报告的运行次数，可使用已有的`sampling.rounds`显式设置，此时输出会注明次数来源。论文中的191次及既有结果未修改。严格达到配置目标的自动取整次数与历史采用的近似覆盖率次数可能略有不同。

随机数改为明确种子、数据检查更严格、GA实现经过模块化整理，因此方法一致不表示重新运行会逐值复现历史AUC、最优参数或图件。没有重新运行研究规模的模型来验证论文数值，也没有改动论文和原始脚本。

已有自动化测试覆盖抽样与覆盖率、选定比例后计算轮数、空间组隔离、折内预处理、预测平均、SHAP汇总、表格与图件输出及模型替换。修改后回归测试全部通过。具体测试环境和数量见`validation.md`。
